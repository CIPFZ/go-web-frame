# Base Frame 问题闭环

日期：2026-09-10。范围为通用基础 CMS，Nexus 的 run/round/case/agent 事件在业务分支实现。

| 原问题 | 修复与验证 |
|---|---|
| 会话无法及时撤销 | SQL session + 用户 token_version。改密、禁用、删除、角色分配/切换后旧会话失效；刷新保留同一登录家族，退出仅撤销本次登录。并发重复续期、MySQL 零更新行与单调过期时间有回归。基础 admin 不可删除、禁用或移除管理员角色。 |
| 权限存在短暂不一致 | 策略和角色/API 关联在一个事务内替换，提交共享 SQL revision；各实例在请求时核对版本并按需加载。双 manager 验证下一次请求撤权；无效 API 引用验证整体回滚。超级管理员仍按框架语义拥有全部 API 权限。 |
| 开户策略不明确 | `system.allow_registration` 默认 false；公开配置只返回注册能力；注册页与登录链接遵循开关。启用时真实创建普通角色 888 的账号；前后端状态码 0/1 对齐，旧冻结状态 2 一次迁移为 0。 |
| 启动重复迁移、seed 恢复撤销授权 | 独立 migrator，MySQL/PG 同连接 advisory lock、SQLite 写锁；已应用步骤不再执行。HTTP 启动只检查 schema 版本。seed 只初始化空用户库，已有菜单、密码及授权归用户维护。并发启动和重跑迁移均回归。 |
| 缺少备份恢复 | `backup.py` 保存一致 SQL/文件/配置快照、SHA-256 校验、14 份保留策略；计划每天北京时间 03:15。恢复到随机项目的新卷，核对文件内容、迁移、就绪、admin 登录、动态菜单。现有 MySQL 8.0 数据已成功导入隔离 MySQL 8.4；正式卷未换引擎。 |
| 观测缺少部署 | 可选 Collector + Prometheus + Loki + Tempo + Grafana，经 8080 `/observability/` 访问；提供持久卷、保留期、仪表盘、规则、真实三信号查询脚本。promtool 验证告警触发与恢复，无外部通知发送。 |
| 配置假热更新 | 去掉只打印消息的 WatchConfig。启动校验端口、JWT 密钥/期限、代理与限流；Redis 有连接/读写/上下文期限，失败关闭连接。配置修改需重启。 |
| 关联完整性 | 用户角色、角色菜单、API token API 校验；菜单父子循环/重复路径、API 重复标识、删除关联的事务保护；角色仍被使用/仍有子角色时不能删除。关键写入共享事务锁，避免查询后并发变化。 |
| 依赖与目录 | main 只负责进程；组装在 `internal/bootstrap`，版本迁移在 `internal/migrations`，seed 在 system 模块；6 类服务移除无用 ServiceContext。 |
| 全局熔断、无限限流状态 | HTTP 不再挂全局入站熔断；IP 桶 10,000 项上限和空闲清理，溢出共享桶；登录/注册独立配额，Redis 启用时跨实例共享。API token 使用 Redis 租约+心跳+取消，无 Redis 时明确是本进程计数。 |
| 前端类型、旧接口文档 | 模块类型显式导出并 import；Swagger 路由从真实注册表生成，请求字段从 DTO 生成；CI 检查生成产物和 45 个前端调用的路径/方法。响应类型仍按模块手工维护。 |
| 状态页视觉与含义 | 整体健康提示、最近更新时间、4 张服务卡片、运行信息和观测入口；主题 token、窄屏布局、手动刷新与异常提示。工作台使用同一依赖状态，不再展示容器/整机含义混杂的 CPU、内存仪表。菜单初始化和升级默认名称同步为“系统状态”。 |

| 中英文切换不完整 | 统一前端语言目录、动态菜单英文名称、权限树、日期与复数、表单及弹窗、请求语言和后端成功/错误/校验响应。切换不刷新页面，保留输入和勾选。菜单 seed/迁移同步，已有自定义数据保留。对 642 条中英文词条增加一致性及 ICU 检查，并接入 CI。 |

## 明确的运行边界

- 权限版本采用每请求 SQL 读取，优先保证小团队场景的一致性；以后扩大流量应测量开销再优化，不能以过期缓存换取撤权延迟。
- SQL 物理外键仍由现有驱动配置关闭。应用内事务保护不约束直接手写 SQL；迁移必须维护关联。
- Redis 并发租约的 handler 必须响应 context 取消；它不是可跨进程强制终止的任务执行器。Nexus 长任务需要自己的持久化租约与 fencing。
- 观测覆盖应用信号与依赖就绪；没有部署主机/容器资源采集器，没有 Nexus 业务通过率，也没有配置邮件/聊天告警通知。
- 自动备份为本机副本，不能覆盖整个磁盘丢失。异机目标需按实际存储配置。
- MinIO/Mongo 可选适配器未做完整外部集成；Umi/Less 上游漏洞、AntD 6 peer 限制延续原评审记录。
